# Grand Capital Financial Services (GCFS)

Official web portal and customer leads management platform for **Grand Capital Financial Services** — Authorized Loan Facilitator & Direct Selling Agent (DSA) based in Boisar, Palghar, Maharashtra.

## 🚀 Features

- **Shriram Finance Aesthetic Design**: Professional, clean UI with customized branding, high-conversion loan application workflows, and responsive layouts.
- **Multi-Loan & Insurance Offerings**: Personal Loans, Business Loans, Instant Cash Loans, Home Loans, LAP, Used & New Car Loans (starting @ 9.99% p.a.), Bajaj Life & HDFC Life Insurance.
- **Instant EMI & Financial Calculators**: Interactive EMI sliders, amortization graphs, and loan comparison tools.
- **Admin Leads Portal (`admin.html`)**:
  - Encrypted military-grade SHA-256 PIN authentication (no exposed credentials).
  - Anti-brute force security lockout.
  - Real-time live lead sync across browser tabs and cloud databases.
  - Export leads to CSV / Excel.
  - Responsive Mobile Card view for on-the-go lead management.
- **Direct WhatsApp & Phone Integration**: Instant lead routing to customer care representatives.
- **Zero White-space & Mobile-optimized**: Designed for high performance on MI, Samsung, and desktop screens.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+)
- **Icons**: Font Awesome 6
- **Typography**: Google Fonts (Outfit, Plus Jakarta Sans)
- **Database / Cloud Sync**: Appwrite Cloud & LocalStorage Fallback
