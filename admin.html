Appwrite Cloud Configuration

100% Free Lifetime Cloud Database (never pauses/sleeps). All customer leads automatically sync here.

Appwrite Console Setup Guide:
  1. Log into cloud.appwrite.io & select project 6abcf17f003452017081
  2. Click Databases > Create database > ID: gcfs_database
  3. Inside it, click Create collection > ID: leads
  4. In Collection Settings > Permissions, add Role: Any, check Create & Read
  5. In Attributes, add String attributes: name, phone, loanType, amount, location, date
